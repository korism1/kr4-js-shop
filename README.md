# Bootstrap Shop

## Контрольная работа №4

Тема «JavaScript: интерактивность, DOM, события, формы и валидация».

Проект `kr4-js-shop` создан на основе [КР №2](https://github.com/korism1/kr2-bootstrap-shop/tree/c792c4fb8f19c60f2a7ad9a51fee4d0fca71ce87) на Bootstrap.

### Практическая работа №15

На главной странице и в каталоге подключены `js/data.js` и `js/main.js` через `defer`. Первый файл содержит объект товара. Второй форматирует цену, рассчитывает скидку и итоговую стоимость, определяет наличие и формирует краткое описание.

Результаты видны в Console и в блоке «Проверка JavaScript» на главной странице. `textContent` выводит строку как текст и предотвращает её интерпретацию как HTML.

### Практическая работа №16

Объект заменён массивом `products` из восьми комплектаций трёх моделей КР №2. Каждая позиция содержит ID, название, категорию, цену, скидку, рейтинг, наличие, изображение, описание и ссылку на страницу модели.

Реализованы получение названий, отбор товаров в наличии, поиск по подстроке и ID, фильтрация по категории, сортировка копии массива, расчёт полной и средней цены и подсчёт наличия. Для примера в Console выводится результат совместного поиска, фильтрации и сортировки. Краткая статистика видна на главной странице.

### Практическая работа №17

Файл `catalog.js` формирует Bootstrap-карточки через `createElement`, `classList`, `textContent` и `append`. Поле поиска, фильтр и сортировка меняют `catalogState` и вызывают `updateCatalog`. Каталог показывает число результатов и сообщение, если совпадений нет. Клики по карточкам обрабатываются одним слушателем контейнера.

Файл `validation.js` проверяет имя, e-mail, телефон и согласие при отправке формы и редактировании полей. Ошибки связаны с полями через `aria-describedby`. Метод `preventDefault()` отменяет отправку браузером.
