# Bootstrap Shop

## Контрольная работа №4

Тема «JavaScript: интерактивность, DOM, события, формы и валидация».

Проект `kr4-js-shop` создан на основе ветки `main` [КР №2 на Bootstrap](https://github.com/korism1/kr2-bootstrap-shop/tree/c792c4fb8f19c60f2a7ad9a51fee4d0fca71ce87). Сохранены Bootstrap 5.3.8, исходные страницы магазина, фотографии и характеристики трёх моделей.

## Запуск

Откройте корень проекта в VS Code и запустите `index.html` через Live Server. Открывайте страницы с одного локального HTTP-адреса, чтобы корзина сохранялась при переходах. Bootstrap загружается через CDN.

## Практическая работа №15

Файлы JavaScript подключены с атрибутом `defer`: сначала данные, затем общие функции и скрипты страницы. В первой ветке `feature/js-basics` объект товара используется для проверки типов данных, операторов и функций `formatPrice`, `calculateDiscount`, `calculateFinalPrice`, `getProductStatus` и `createProductSummary`. Результаты видны в Console и блоке «Проверка JavaScript».

## Практическая работа №16

В ветке `feature/products-array` объект заменён массивом из восьми учебных комплектаций трёх моделей. Каждая позиция содержит `id`, `title`, `category`, `price`, `discountPercent`, `rating`, `isAvailable`, `image`, `description` и `detailsPage`. Цены, рейтинги и наличие используются как учебные данные.

- `getProductTitles`, `getAvailableProducts` и `countAvailableProducts` получают названия и данные о наличии.
- `searchProducts`, `filterProductsByCategory`, `sortProductsByPrice` и `getPreparedProducts` подготавливают список для каталога. Сортируется копия массива.
- `findProductById` находит товар по числовому ID, `calculateTotalPrice` и `calculateAveragePrice` рассчитывают статистику.
- На главной показаны число товаров, наличие, общая и средняя цена, число совпадений по запросу «zenbook» и пример расчёта цены со скидкой.

## Практическая работа №17

Каталог формирует карточки через `createElement`, `classList`, `textContent` и `append`. Поиск сопоставляет часть названия без учёта регистра и крайних пробелов. Фильтр отбирает товары по категории. Сортировка доступна по базовой цене в обе стороны и по названию. Поиск, фильтр и сортировку можно применять одновременно. Изменение любого параметра вызывает `updateCatalog`, обновляет счётчик и при необходимости показывает пустое состояние. Один обработчик `click` на сетке принимает события от кнопок всех карточек.

Форма проверяет имя от двух символов, формат e-mail, 11 цифр телефона с начальной 7 или 8 и согласие. Ошибки появляются рядом с полями, а фокус при отправке переходит к первому полю с ошибкой. Обработчики подключены через `addEventListener`. Для текстовых данных применяется `textContent`, который отображает строку без интерпретации как HTML. Приложение выводит сообщения прямо на странице.

## Практическая работа №18

- Товары в наличии добавляются в корзину. Можно изменить количество и удалить позицию. Сумма по позициям рассчитывается через `reduce`, с учётом скидок на сами товары.
- Промокод `SHOP10` уменьшает сумму товаров ещё на 10%. Пустой код снимает скидку.
- ID, количество и применённый промокод записываются в `localStorage` как JSON. При загрузке проверяются структура, доступность товаров и предел количества. Счётчик в навигации показывает число единиц товара.
- При уходе из поля корректный телефон приводится к формату `+7 (900) 000-00-00`. Успешная проверка очищает форму и открывает `dialog`. Кнопка закрытия и Escape возвращают фокус. После успешной заявки из корзины корзина очищается.
- Заявка имитируется в браузере через `preventDefault()`. Контакты и комментарии в хранилище браузера не записываются.

## Проверка перед защитой

1. Откройте главную и найдите таблицу `products` в DevTools → Console. В блоке «Проверка JavaScript» должно быть восемь позиций и шесть в наличии.
2. В каталоге введите ` ZENBOOK `, выберите «Ультрабуки Windows» и отсортируйте по убыванию цены. Должны остаться три карточки ASUS в порядке от 145 000 до 110 000 руб. По запросу без совпадений появляется сообщение, а счётчик показывает ноль.
3. Для проверки в DevTools → Sources поставьте точку останова в `updateCatalog` на строке с вызовом `renderProducts`. Измените запрос и проверьте `catalogState` и `preparedProducts`.
4. Добавьте две единицы MacBook Air 8/256 ГБ. Сумма составит 199 500 руб. Примените `SHOP10` и проверьте итог 179 550 руб. После перезагрузки количество и скидка сохраняются.
5. На форме отправьте пустые поля, затем проверьте адрес `student@` и телефон с лишней цифрой. Для успешного сценария введите имя «Тест», e-mail `student@example.org`, телефон `8 (999) 123-45-67` и отметьте согласие. Проверьте очистку формы, диалог и возврат фокуса.
